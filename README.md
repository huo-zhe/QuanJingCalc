# 全境征才计算器 (自动辅助助手)

> 自动全境征才，大体没问题，可能有小问题。

这是一个基于 Android 无障碍服务 (AccessibilityService) 与 OCR (文字识别) 的《天下布魔》全境征才自动化辅助工具。

## ✨ 功能特性
- **悬浮球手动模式**：点击悬浮球自动识别词条并给出推荐（或直接选择）。
- **全屏结果面板**：按稀有度渐变显示最佳组合。
- **全自动模式**：
  - 自动轮询 4 大榜单。
  - 内置 OCR 识别与标签防错。
  - 智能检测紧急征才、一键录取、SKIP 与自动关闭。
  - 遇到 3★ 领袖词条会暂停并弹窗提示。
- **多设备适配**：内置线性插值算法，自动适应不同分辨率的手机屏幕（特别是全面屏/带鱼屏）。
- **底层突破**：针对小米/红米等限制严苛的系统，利用全屏声明与微滑动技术，完美解决底部无法点击的问题。

## 📱 使用说明
1. 在手机上安装并打开 App。
2. 授予 **悬浮窗权限** 与 **无障碍服务权限**。
3. 点击“启动悬浮球”，同意**屏幕录制（录屏）**请求（用于 OCR 截图）。
4. 进入游戏，按照 App 内的提示完成**两套点位校准**（招募条件 6点 / 自动点位 8点）。
5. 点击悬浮球即可使用手动模式，长按悬浮球可选择全自动模式。

## ⚠️ 注意事项
- **机型适配**：虽然已做多分辨率适配，但部分极端系统（如开启了开发者选项中的强制缩放）可能依然会有微小偏移，建议重新校准一次即可解决。
- **OCR 依赖**：请确保游戏界面亮度适中，以免影响文字识别准确率。
- **免责声明**：本工具仅供学习交流与简化重复操作使用，请合理控制使用频率。
